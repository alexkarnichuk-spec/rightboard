# RightBoard — новый сайт

Статический сайт на основе контента rightboard.ru (бывший Taplink-лендинг).
Без сборки, без зависимостей, без `node_modules` в самом сайте: чистые HTML + CSS + один маленький JS.

## Как посмотреть

**Вариант 1 — просто открыть файл.** Двойной клик по `index.html`. Всё работает,
включая шрифт и картинки.

**Вариант 2 — локальный сервер** (ближе к продакшену, правильные MIME-типы):

```powershell
cd rightboard-site
python -m http.server 8123
```

Затем открыть <http://127.0.0.1:8123/>.

Скриншоты последней проверки лежат в `tools/qa/shots/`:
`desktop-1440.png`, `mobile-375.png` (полная страница), плюс остальные ширины.

## Дизайн-система «Минерал» v2

Не «карточки на бежевом», а редакционная раскладка: волосяные линии вместо
коробок, острая геометрия (радиус 3 px), крупная типографика, номер секции
в каждой голове, пары «широкая колонка — узкая подпись».

Палитра выведена из самих фотографий (средние тона: `#a68775`, `#96908b`, `#7d8696`),
поэтому снимки «садятся» в фон без конфликта.

| Токен | HEX / значение | Роль |
|---|---|---|
| `--paper` | `#F5F1E8` | основной фон |
| `--paper-2` | `#FBF8F1` | подложки |
| `--sand` | `#E9E0CF` | чередующиеся секции |
| `--line` | `rgb(23 22 16 / 16%)` | волосяные линии — несут всю структуру |
| `--ink` | `#17160F` | заголовки и текст |
| `--muted` | `#635C50` | вторичный текст (контраст ≥ 4.5 проверен) |
| `--bronze` | `#A26B36` | акцент, номера, линии-действия |
| `--bronze-deep` | `#7E5124` | мелкий акцентный текст (крупнее по контрасту) |
| `--clay` | `#8E4630` | «проблема»: ДПК |
| `--mineral` | `#3F5248` | «решение»: МПК |
| `--graphite` | `#16150F` | тёмные секции: проблема, о нас, футер |

Типографика: **Golos Text** (OFL, кириллица родная), вариативный вес 400–900.
Заголовок хиро — 5,1 rem с трекингом −0.04em и межстрочным 0.98.
Служебный текст — капс 0.685 rem с разрядкой 0.16–0.22em.

Структурные приёмы:
- **номер секции** (01…07) в голове каждой секции — задаёт ритм и позволяет
  переосмыслить меню без «Проблема / Материал / Проверка»;
- **«Проблема»** — тёмная секция с таблицей-индексом: `01 · Цвет ушёл · описание`
  в три колонки, без картинок и коробок;
- **кейсы** — редакционная сетка 12 колонок (8+4, затем 3+3+3+3), а не одинаковые плитки;
- **сравнение** — таблица только с линиями, шапка на волосяной линии цвета чернил;
- **о нас** — таймлайн 2022 → 3 месяца → сейчас вместо абзацев.

## Правила, которые соблюдаются

- **Никакого JS для раскладки.** Сайт полностью читается без JavaScript
  (проверяется автоматически: 23/23 теста, включая «без JS контент доступен»).
- **Кросс-платформенность.** Проверено в реальном Chrome на 320 / 375 / 414 / 768 /
  900 / 1024 / 1440 / 1920 px. Ноль горизонтального переполнения. Учтены
  `viewport-fit=cover`, `env(safe-area-inset-*)`, `prefers-reduced-motion`.
- **Доступность AA.** Контраст всех текстовых пар ≥ 4.5, тап-цели ≥ 40 px,
  `:focus-visible`, skip-link, alt у всех изображений, семантика и `aria-*`.
- **Вес.** Первый экран мобильной версии ≈ 400–500 КБ на несжатом сервере
  (с gzip/brotli на реальном хостинге ~350–400 КБ). AVIF — основной формат,
  WebP — фолбэк. Всё ниже первого экрана `loading="lazy"`.
- **Видео не грузится заранее.** Kinescope вставляется только по клику
  (фасад с постером), поэтому чужие скрипты не тормозят страницу.

## Как обновлять

**Текст и разметка.** Редактировать `.html` напрямую — никакой сборки.

**Фотографии.** Складывать оригиналы в `content/images/`, затем:

```powershell
python tools/pipeline.py
```

Скрипт сделает все ширины в AVIF и WebP, пересоберёт логотип и обновит
`content/manifest.json` (размеры нужны для `width`/`height` в разметке — чтобы не было сдвига вёрстки).

**Проверка после правок.**

```powershell
python -m http.server 8123        # в отдельном окне
node tools/qa/check.mjs           # вёрстка, контраст, вес
node tools/qa/functional.mjs      # поведение и структура
node tools/qa/rhythm.mjs          # композиция секций
```

`tools/qa` — единственное место с зависимостями (`puppeteer-core`).
Он управляет уже установленным Chrome, браузер не скачивается. Самому сайту это не нужно.
